# Sistema de Busca Otimizado para Catálogo de Produtos - MegaStore

## Descrição do Projeto
O sistema de busca da MegaStore é uma aplicação desenvolvida em Rust com o objetivo de indexar o catálogo de produtos da loja e permitir buscas extremamente rápidas e precisas. O sistema foi projetado com foco em alta performance e escalabilidade, garantindo que os clientes encontrem o que desejam sem latência perceptível, mesmo com o crescimento do catálogo.

## Tecnologias Utilizadas
* **Linguagem:** Rust
* **Gerenciador de Pacotes e Build:** Cargo
* **Crates Principais:** * `serde` e `serde_json` (exemplo: para manipulação de dados)
  
* **Ferramentas de Teste:** Testes nativos do Rust (`cargo test`)
